# ICMS 2027 – Multi-Page Website

Pages:
- index.html — Home
- about.html — About ICMS 2027 & Scientific Themes
- programme.html — Scientific Programme
- speakers.html — Leadership & Speakers
- abstract.html — Abstract Submission
- registration.html — Registration & Payment
- venue.html — Venue, Ayodhya, Accessibility, Climate & Accommodation
- contact.html — Contact

Upload all files and folders to the root of the GitHub Pages repository. Keep the `images` folder alongside the HTML files and `style.css`.

The website remains a static HTML/CSS/JavaScript site, so no server-side setup is required.
