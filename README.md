# ICMS 2027 Website

Static HTML/CSS website for the International Conference on Microbiological Sciences (ICMS 2027).

## Files
- index.html — complete website
- style.css — responsive styling

## How to use
1. Keep `index.html` and `style.css` in the same folder.
2. Open `index.html` in a browser to preview.
3. Replace the `#` registration and abstract-submission links with the real forms.
4. Add confirmed speaker photos/names when available.
5. Upload both files to GitHub Pages, Netlify, or another static hosting service.
